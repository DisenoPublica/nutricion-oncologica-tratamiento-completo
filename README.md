# Encuesta #TratamientoCompleto

Encuesta para celulares, web y tótems. Las respuestas se guardan en Google Sheets mediante Apps Script.

- `index.html`: la encuesta (archivo único, sin dependencias).
- `google-apps-script/Code.gs`: script pegado en el Google Sheet (referencia).

## Publicar en Netlify
Add new site → Import from Git → elegir este repositorio. Build command: vacío. Publish directory: `/`.

## Tótem
Usar la URL con `?canal=totem` (reinicio automático).
